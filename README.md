# JAKWO War Ads Arena Static Build

Deploy this as static files on Vercel/GitHub. No npm, no Next.js.

Root files:
- index.html
- upload.html
- story.html
- admin.html
- style.css
- script.js
- config.js
- assets/memes/
- vercel.json
- supabase-schema.sql

Supabase:
Paste `supabase-schema.sql` into Supabase SQL Editor and Run.

Admin:
Open `/admin.html` and use password from `config.js`.
Default: JAKWOADMIN2026

Voucher tiers:
- $1000 max 50
- $500 max 50
- $100 max 100
- $0.50 max 200

All vouchers: no expiry, one-time use, transferable as code, no cash value, wallet required.
